### Weight Scale

| Weight     | Situation                                                                                                      |
| ---------- | -------------------------------------------------------------------------------------------------------------- |
| Light      | Single short vowel                                                                                             |
| Heavy      | Long vowel, [[Diphthong]], vowel followed by Coda consonant ([[Doubling rule - VCV pattern\|Closed Syllable]]) |
| Superheavy | 3 morae - Rare, like long vowel + consonant                                                                    |
