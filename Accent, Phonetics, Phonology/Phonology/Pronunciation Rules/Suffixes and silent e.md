[[Silent e pattern|Silent E]]

### Suffix beginning with vowel 
**When**: Suffix beginning with vowel added to a word
[^1]**Do**: Remove the e.

| Word   | After adding suffix |
| ------ | ------------------- |
| Cope   | Coping              |
| Love   | Loving              |
| Secure | Security            |
| Create | Creator             |
|        |                     |

### Keeping silent-e when removing it makes soft c and g hard when suffix does not start with e, i, y
[[Silent e making C and G soft when after it]]

Silent e keeps the C and G soft.
If additional suffix started with e, i, y - It would have kept the c and g soft so we could remove the e.
In absence of e-i-y at the beginning of the suffix, the removal of silent e would cause the c and g to become hard. 
Hence we do not remove silent-e when it is preceeded by C and G; and the suffix does not starts with e-i-y


> If dropping the **e** would change a **soft `c` (/s/)** into a **hard `c` (/k/)**, or a **soft `g` (/dʒ/)** into a **hard `g` (/ɡ/)**, then **keep the silent `e`**.

| Base Word | Suffix | Result | Keep Silent e? | Reason |
|-----------|--------|--------|----------------|--------|
| change | -able | changeable | ✅ Yes | Prevents **g** from becoming hard before **a**. |
| outrage | -ous | outrageous | ✅ Yes | Prevents **g** from becoming hard before **o**. |
| courage | -ous | courageous | ✅ Yes | Keeps **g** = /dʒ/. |
| notice | -ing | noticing | ❌ No | **ci** already makes **c** soft. |
| manage | -ing | managing | ❌ No | **gi** already makes **g** soft. |
| trace | -able | traceable | ✅ Yes | Prevents **c** from becoming /k/ before **a**. |
| peace | -able | peaceable | ✅ Yes | Keeps **c** = /s/. |

[^1]: Inconsistently applied, like in the case of change - where it becomes changeable.
