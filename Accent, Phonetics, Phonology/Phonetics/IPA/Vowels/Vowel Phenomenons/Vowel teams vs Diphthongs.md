[[Vowel Teams]]
[[Diphthong]]

| Term           | Think of...                 | Question it answers                               | Example                                             |
| -------------- | --------------------------- | ------------------------------------------------- | --------------------------------------------------- |
| **Vowel team** | **How the word is spelled** | "How many vowel letters work together?"           | **ea** in _team_, **oa** in _boat_, **ee** in _see_ |
| **Diphthong**  | **How the word sounds**     | "Does the vowel glide from one sound to another?" | /aɪ/ in _time_, /eɪ/ in _day_, /ɔɪ/ in _boy_        |

**Some vowel teams are not diphthongs, Some diphthongs are not written with vowel teams.**

| Word | Vowel Team   | Sound                  | Diphthong? |
| ---- | ------------ | ---------------------- | ---------- |
| see  | ee           | /iː/                   | ❌ No       |
| moon | oo           | /uː/                   | ❌ No       |
| team | ea           | /iː/                   | ❌ No       |
|      |              |                        |            |
|      |              |                        |            |
| Word | Spelling     | Diphthong              |            |
| time | i + silent e | /aɪ/                   |            |
| home | o + silent e | /oʊ/ (AmE), /əʊ/ (BrE) |            |
| name | a + silent e | /eɪ/                   |            |
