The letter C can be pronounced as either K or S, depending on the situation.

| Situation                | Result                        | Example     |
| ------------------------ | ----------------------------- | ----------- |
| When C is followed by a vowel sound that is A, O, U, or sometimes other vowels, in the same syllable or later in the word | C is pronounced as K | Cat, Car, Clay    |
| When C is followed by a vowel sound that is E, I, or Y, in the same syllable or later in the word | C is pronounced as S | Cell, Cinema | 

Note that the pronunciation of C is determined by the vowel sound that follows it, not necessarily the immediate letter. This means that the presence of consonants between C and the vowel sound does not change the pronunciation of C.


#### Double C
When **CC** is followed by **E, I, or Y**, the first **C** is usually /k/ and the second softens:
- accident → /ˈæk.sɪ.dənt/
- accept → /əkˈsept/
- success → /səkˈses/
In many words, this results in the sound sequence **/ks/**.
Examples:
- accident → /ˈæk.sɪ.dənt/
- success → /səkˈses/
- access → /ˈæk.ses/



| Situation                  | Pronunciation              | Example                         |
| -------------------------- | -------------------------- | ------------------------------- |
| Jab C ke baad A, O, U aaye | Tab ussey **K** padhte hai | Cat, Car, Clay (kat, kar, klay) |
| Jab C ke baad E, I, Y aaye | Tab ussey C padhte hai     | Cell, Cinema (sell, sinema)     |

# The Rule to Memorize

| Following Letter | Sound |
|------------------|-------|
| **E** | **/s/** |
| **I** | **/s/** |
| **Y** | **/s/** |
| **A** | **/k/** |
| **O** | **/k/** |
| **U** | **/k/** |
| **Consonant** | **/k/** |
| **End of word** | **Usually /k/** |

> **Mnemonic:**  
> **C + E, I, Y → /s/** (Soft C)  
> **C + A, O, U, consonant, or word end → /k/** (Hard C)
