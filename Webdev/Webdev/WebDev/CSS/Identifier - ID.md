[[Identifier - Classes]]


#Q #AOSR/55u3f
What kind of identifier is an ID
? #AOSR/55u3f/m/5gjp
- **IDs**: ==unique== #AOSR/55u3f/c/91j8  element identifiers for HTML elements. ID names should only be used ==once== #AOSR/55u3f/c/6sj6  per HTML document.

```html
<h1 id="title">Movie Review Page</h1>
```

#Q #AOSR/547b0
Can ID Names have spaces
? #AOSR/547b0/m/z471
ID names ==cannot== #AOSR/547b0/c/28jt  have spaces. If your ID name contains multiple words then you can use dashes between the words like this:

```html
<div id="red-box"></div>
```
