In CSS, ==**`vh` stands for viewport height**== #AOSR/7nkv3/c/1naa , which is a relative length unit representing **1% of the total height of the browser's visible screen area (the viewport)**. [[1](https://www.geeksforgeeks.org/css/explain-the-concept-of-the-vh-and-vw-units-in-css/), [2](https://lacolmenatecnologica.com/en/elementor-academy-temas/what-is-the-difference-between-px-em-rem-vw-and-vh/)]
For example, if a user's browser window is 1,000 pixels tall, an element styled with `height: 50vh;` will dynamically scale to exactly 500 pixels (50% of the screen height)
