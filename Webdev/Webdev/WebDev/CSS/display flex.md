display: flex;

[[Flexbox model]]

**`display: flex;`** ==is a CSS property that activates the **Flexbox (Flexible Box) layout module** on a parent container==. This instantly converts the container's direct child elements into **flex items**, giving you precise control over their alignment, spacing, sizing, and order along a single dimension (either a row or a column).
