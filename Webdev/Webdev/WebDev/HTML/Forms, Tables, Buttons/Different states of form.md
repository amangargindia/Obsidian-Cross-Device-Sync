#Q
What are different states of forms
?
1. Default
2. Focused
3. Disabled
4. Readonly

#Q 
How do you put form states in in a form
?
You put the attribute in `input` element.

#Q
What is Disabled and Readonly element in form
?
Both elements do not allow user to enter anything in the input field.

#Q
What is difference between Disabled and Readonly element in form
?
Readonly form can be focused using tab but not Disabled one.
