#Q
How to add a number input in html form
?
You can add a number input by putting `number` as the value for the attribute `type=""` in the `<input></input>` element of `<form></form>` 

#Q
How can you limit the minimum or the maximum number that can be entered in a number field
?
you can do so using the `min=""` and `max=""` element in `<input type="number></input>` 

#Q
What is the difference between `min, max` and `minlength, maxlength`
?
Min and max are to limit the range of number that can be entered, while minlength and maxlength are to limit the number of characters that can be entered in a text field.
