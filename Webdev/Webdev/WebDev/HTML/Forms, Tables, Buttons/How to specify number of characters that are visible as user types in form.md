#Q 
How to specify number of characters that are visible as user types in form
?
Using the `size` attribute inside `<input><input>` element in form.

#Q
How is size element different from `minlength=""` or `maxlength=""` attribute for forms
?
Those two set the limit of how many characters can be entered.
Size element only limits the visual area, not the ability to limit the amount of text entered in it.
