? #AOSR/5ccia/m/7dfi
Using the datetime time element with datetime attribute.

#Q #AOSR/4u18d
How is date written in time element
? #AOSR/4u18d/m/1m98
The value for the `datetime` attribute is in the ISO 8601 format. ISO 8601 is an international standard to represent dates and times.
The first part of that value is the year, month and day. The capital T in the value is a separator between the date and time. Time is written in 24 hour clock format.
