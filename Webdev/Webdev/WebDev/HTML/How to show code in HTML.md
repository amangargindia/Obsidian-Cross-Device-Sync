
# Inline code

#Q #AOSR/1jo92
How to show a code
? #AOSR/1jo92/m/37e5
If the code is small, you use `<code></code>` element, which puts it inline.

#Q #AOSR/591t6
How to show a longer code
? #AOSR/591t6/m/4kgo
You wrap the `<code></code>` element with `<pre></pre>` which means preformatted text.
```
<pre>

  <code>

    body {

      color: red;

    }

  </code>

</pre>
```

#Q #AOSR/2v980
How do you show preformatted text
? #AOSR/2v980/m/2ab2
Using `<pre></pre>` element.
